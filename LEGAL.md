## How it was made

The client reproduces the behaviour of the original game (formulas, timings, network packet
formats) so that it can work with existing servers. That behaviour was studied from public
sources listed in the README, from open-source server projects and by observing the game. Tables
in the repository hold facts (numbers, ids, layouts) needed for compatibility.
